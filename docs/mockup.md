# Workstation — Visual Mockup

## Color Palette

| Element | Color | Hex |
|---|---|---|
| Canvas background | Near black | `#0a0a0f` |
| Node cards | Dark surface | `#111118` |
| Node borders | Subtle | `#1e1e2e` |
| Accent / glow | Green (Supabase-inspired) | `#00ff88` |
| Terminal text | Monospace green | `#00ff88` |
| Chat text | Clean white | `#e2e8f0` |
| Lines (idle) | Faint | `#2a2a3e` |
| Lines (active) | Glowing | `#00ff8860` |
| Dashed (open tangent) | Muted | `#3a3a5e` |
| Solid (resolved tangent) | Confirmed | `#00ff8840` |
| Progress bar fill | Green | `#00ff88` |
| Pills (minimized) | Subtle surface | `#1a1a2e` |

## Design Principles

- **One thing glows at a time** — active node only
- **Canvas has a dot grid** — feels like a workspace, not a void
- **Depth** — background nodes slightly blurred, active node sharp
- **Supabase DNA** — deep dark, green accent, clean typography, premium spacing
- **No clutter** — everything minimizable, nothing forced visible
