# Workstation — Visual Mockup

## Color Direction: Dark / Futuristic / Premium (Supabase-inspired)

### Accent Color
- **Primary green:** `#3ECF8E` (Supabase green)
- **Canvas background:** `#0a0a0f`
- **Node cards:** `#1a1a2e`
- **Active node border glow:** `#3ECF8E`
- **Lines (main flow):** `#3ECF8E` at 60% opacity
- **Lines (tangent, open):** `#3ECF8E` dashed at 40% opacity
- **Lines (tangent, resolved):** `#3ECF8E` solid at 80% opacity
- **Text:** `#ffffff` primary, `#888899` secondary
- **Terminal text:** `#3ECF8E` on `#000000`

### The Canvas
![Workstation Canvas Mockup](./mockup.jpg)

### What You're Looking At
- **Main flow** runs left → right: Overview Chat → Auth → Payments → Dashboard
- **Active node** has the single green glow — everything else is calm
- **Tangent** drops down from Auth with a dashed line, ties back to Payments with a solid curve
- **Minimized pills** sit in the bottom right corner
- **Progress bar** at top, 60% filled in Supabase green
- **Dot grid** on canvas — feels like a workspace, not a void
- Each node card: **terminal left** | **chat right**

### Typography
- Headers: `Inter` or `Geist` (Vercel's font — clean, modern)
- Terminal content: `JetBrains Mono` or `Fira Code`
- UI labels: `Inter` at various weights

### Feel
Premium. Dark. Focused. Like Supabase met Linear met a coding environment.
